# صندوق العائلة 💰

نظام عربي لإدارة صندوق العائلة، يساعد على تنظيم اشتراكات الأعضاء والإيرادات والمصروفات وطلبات المساعدة والتقارير المالية بسهولة.

## 🌐 تشغيل البرنامج

▶️ [فتح برنامج صندوق العائلة](https://adelss12.github.io/family-fund/)

يعمل البرنامج مباشرة من المتصفح، ويمكن استخدامه على الكمبيوتر أو إضافته إلى الشاشة الرئيسية في الآيفون للوصول إليه بسرعة.

## ✨ المميزات

- إدارة أعضاء صندوق العائلة.
- تحديد قيمة الاشتراك لكل عضو.
- متابعة الاشتراكات الشهرية والمدفوعات.
- تسجيل الإيرادات والمصروفات.
- متابعة المبالغ المتبقية على الأعضاء.
- إدارة طلبات المساعدة واعتمادها.
- عرض ملخص مالي للصندوق.
- تقارير مالية ومتابعة حركة الصندوق.
- واجهة عربية مناسبة للجوال.
- يعمل مباشرة من المتصفح.

## 📱 إضافة البرنامج إلى شاشة الآيفون

افتح البرنامج في Safari، ثم اضغط زر المشاركة واختر **إضافة إلى الشاشة الرئيسية**.

سيظهر البرنامج باسم **الصندوق** مع أيقونته الخاصة.
